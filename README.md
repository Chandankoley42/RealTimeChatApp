# Real-Time Chat Application

A full-stack real-time chat application built using the MERN stack, Socket.io, and Tailwind CSS.  
This application allows users to chat instantly with real-time messaging and online user status support.

---

# Features

## Authentication & Authorization
- User Signup
- User Login
- JWT Authentication
- Protected Routes
- Logout Functionality
- Update User Profile

---

## Real-Time Chat Features
- Real-time messaging using Socket.io
- Instant message delivery
- Online user status
- Live chat updates
- Chat sidebar
- Chat container UI

---

## Frontend Features
- React.js frontend
- Tailwind CSS styling
- Daisy UI components
- Zustand state management
- Responsive design
- Modern UI/UX
- Settings page
- Profile page

---

## Backend Features
- Node.js server
- Express.js REST APIs
- MongoDB database
- Mongoose models
- Socket.io integration
- Error handling
- JWT authentication middleware

---
